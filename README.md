# Dungeon Quest

홍익대학교 컴퓨터공학과 졸업 프로젝트로, 4인 팀이 Unity로 개발한 2D 플랫포머 멀티플레이 게임입니다.

> 이 저장소는 팀 저장소를 포크한 것입니다. 원본: [penguin0305/project-2D](https://github.com/penguin0305/project-2D)

## 게임 소개

최대 4명의 유저가 같이 던전을 탐색하고 몬스터를 처치하며 아이템을 획득하고,  
아이템 컬렉션을 강화해가며 계정을 성장하는 2D 플랫포머 게임입니다.

## 담당 작업

### 플레이어 상태 머신
- 지상, 공중, 사다리, 경직, 사망 다섯 상태를 인터페이스 기반 상태 머신으로 구현했습니다.
- 입력, 이동, 감지, 전투, 애니메이션을 각각 별도 컴포넌트로 분리했습니다.

### 네트워크 유무에 따른 캐릭터 분리
- 네트워크가 없는 씬에서도 같은 캐릭터를 쓸 수 있도록 `NetworkBehaviour` 버전과 `MonoBehaviour` 버전을 나눴습니다.
- 이동, 입력, 감지 컴포넌트는 두 버전이 공유합니다.

### 동기화 구조
- 동기화할 값을 `PlayerSync` 컴포넌트 한 곳에 모았습니다.
- 방향, 이동량, 접지 여부는 소유 클라이언트가 쓰고, 체력은 서버가 쓰도록 `NetworkVariable`의 쓰기 권한을 나눴습니다.
- 상태로 표현되지 않는 공격 모션은 RPC로 전파했습니다.

### 피격 처리
- 피격 인터페이스(`IDamageable`)와 피해 정보 구조체(`DamageInfo`)로 플레이어, 적, 함정이 같은 경로로 피해를 주고받게 했습니다.
- 피해량이 떠오르는 Floating Damage 효과를 구현했습니다.

### 수집 요소 강화
- 수집 요소를 강화하면 보너스 스탯이 붙는 시스템을 만들었습니다.
- 강화 연산을 인터페이스(`IEnhanceService`)로 분리해, 현재의 로컬 구현을 나중에 서버 구현으로 바꿀 수 있게 했습니다.

## 팀원 담당 (참고)

로비, Relay, 인증 등 세션 연결 부분과 적, 보스, 인벤토리, 스테이지 관리는 다른 팀원이 작업했습니다.

## 사용 기술

C#, Unity 6, Netcode for GameObjects (NetworkVariable, RPC), Input System, Git
